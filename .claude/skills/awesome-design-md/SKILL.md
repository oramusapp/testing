# Awesome DESIGN.md

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see LICENSE).

Each folder in `design-md/<site>/` contains a `DESIGN.md` describing that site's visual design system.

## How to use

1. List available sites: `ls .claude/skills/awesome-design-md/design-md/`
2. Read the matching `design-md/<site>/DESIGN.md` for the requested style.
3. Apply its tokens (color, type, spacing, radius, shadows, component patterns) to the UI being built. Use it as inspiration; do not copy logos, brand names, or trademarked assets.
